# ES6 Basics

## Description
This project is an introduction to ES6 (ECMAScript 2015) and the features it introduced to JavaScript. ES6 brought major syntax and language improvements that made JavaScript easier to write, read, and maintain.

In this project, we focus on:

- Block-scoped variables with `const` and `let`
- Arrow functions and default parameters
- Rest and spread syntax
- Template literals for string interpolation
- Object creation shorthand and ES6 method properties
- Iterators, iterables, and `for...of` loops

The main goal of this project is to understand the differences ES6 introduced compared to ES5, and how these features lead to cleaner, safer JavaScript code.

## Installation
Clone the repository:
```
git clone https://github.com/RahafN1/holbertonschool-web_back_end.git
```

Move into the project directory:
```
cd holbertonschool-web_back_end/ES6_basic
```

Install dependencies:
```
npm install
```

## Requirements
- Ubuntu 20.04 LTS
- Node.js 20.x.x
- npm 9.x.x
- Code is tested with the Jest Testing Framework
- Code is analyzed with ESLint (airbnb-base config)
- All files end with a new line
- All functions must be exported

## Usage
Run a file with Babel node:
```
npm run dev <filename>.js
```

Run the linter:
```
npm run lint
```

Run the tests:
```
npm test
```

Run lint + tests together:
```
npm run full-test
```
